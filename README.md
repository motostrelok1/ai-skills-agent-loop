# AI Skills Agent Loop

Коллекция скиллов для AI-агентов: планирование, разработка через TDD, проверка кода, тестирование и публикация pull request.

## Скиллы

| Скилл | Назначение |
| --- | --- |
| [agent-loop](agent-loop/SKILL.md) | Координация агентов планирования, разработки, ревью и публикации. |
| [planning-and-task-breakdown](planning-and-task-breakdown/SKILL.md) | Разбиение требований на задачи с критериями приёмки и проверками. |
| [tdd](tdd/SKILL.md) | Разработка через цикл «падающий тест → реализация». |
| [code-review](code-review/SKILL.md) | Проверка изменений на соответствие стандартам и требованиям. |
| [manual-automation](manual-automation/SKILL.md) | Автоматизация ручного тестирования через Chrome DevTools MCP. |
| [e2e-test](e2e-test/SKILL.md) | Сквозное тестирование приложения Boek 7 в браузере. |
| [qa](qa/SKILL.md) | Сбор сообщений об ошибках и создание GitHub issues. |
| [pull-request](pull-request/SKILL.md) | Создание ветки, коммита и pull request через GitHub CLI. |

## Использование

Откройте `SKILL.md` нужного скилла и подключите его к используемому AI-агенту согласно правилам этого инструмента. Требования к окружению и дополнительным инструментам указаны в соответствующем скилле.

Файлы скиллов перенесены из исходного архива без изменений. Некоторые инструкции ссылаются на внешние скиллы и файлы конкретных проектов, которые не входят в эту коллекцию.
